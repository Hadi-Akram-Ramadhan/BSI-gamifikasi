# Duel Cerdas — Jago Atur Uang

**Game edukasi literasi finansial untuk siswa kelas 4–6 SD.** Bersama maskot Koini, pemain belajar mengenal uang, membedakan kebutuhan dan keinginan, menabung, berbagi, serta menyusun rencana melalui materi interaktif, kuis, mini-game, dan duel kelas.

Proyek ini merupakan prototipe interaktif berbasis web. Seluruh nominal uang, tabungan, poin, dan hadiah merupakan simulasi pembelajaran.

## Tujuan permainan

Duel Cerdas membantu anak berlatih mengambil keputusan sederhana tentang uang dalam situasi sehari-hari. Pemain diajak memahami alasan di balik pilihan mereka, mencoba kembali ketika keliru, dan merayakan perkembangan belajar melalui XP, bintang, dan lencana.

Permainan dapat digunakan secara mandiri atau didampingi guru dan orang tua. Mode duel menyediakan kegiatan bersama dengan kontrol guru dan tampilan arena untuk layar besar.

## Enam dunia belajar

Setiap dunia memiliki penjelasan, contoh, aktivitas, dan kuis berisi 8 soal. Total tersedia 48 soal dengan pembahasan.

| Dunia | Hal yang dipelajari |
| --- | --- |
| Kenal Uang & Nilainya | Mengenali nilai rupiah dan menghitung kesetaraan uang. |
| Kebutuhan vs Keinginan | Menentukan prioritas belanja sesuai keadaan. |
| Menabung Itu Seru | Menyisihkan uang secara bertahap untuk mencapai tujuan. |
| Indahnya Berbagi | Memahami kebaikan dan berbagi sesuai kemampuan. |
| Rencana & Target | Menghitung kebutuhan dana dan membuat rencana sederhana. |
| Aku Makin Cerdas | Merefleksikan keputusan dan memperbaiki kebiasaan. |

## Cara bermain mandiri

1. Dari beranda, pilih **Mulai Petualangan**.
2. Pilih salah satu dunia belajar, baca materi, dan coba aktivitasnya.
3. Selesaikan materi lalu lanjutkan kuis. Perhatikan pembahasan untuk memahami jawaban.
4. Kunjungi **Zona Mini Games** untuk melatih pengetahuan melalui tantangan singkat.
5. Buka **Tabunganku** untuk mencoba pencatatan tabungan dan memantau target.
6. Lihat perkembangan XP, bintang, dan lencana melalui profil dan halaman pencapaian.

Materi dan permainan dapat diulang untuk berlatih. Hadiah untuk aktivitas yang sama tidak diberikan berulang kali setelah sudah diterima.

## Duel individu dan tim

Duel mempertemukan dua sisi, Hijau dan Oranye, dalam pertandingan soal literasi finansial. Guru mengatur room, menjalankan pertandingan, dan memandu pembahasan.

### Alur pertandingan

1. Buka **Main Duel**, lalu pilih **Duel Individu** atau **Duel Tim**.
2. Buat room dan tentukan pengaturan pertandingan serta cara menjawab.
3. Masukkan peserta atau gunakan **Isi Pemain Demo** untuk mencoba alur dengan cepat.
4. Klik **Buka Smart TV** untuk menampilkan lobby dan arena di tab terpisah.
5. Mulai pertandingan dari kontrol guru. Hitung mundur mengantar pemain ke soal pertama.
6. Kirim jawaban sebelum waktu habis. Jawaban yang sudah dikirim akan terkunci.
7. Tinjau jawaban dan pembahasan, kemudian lanjutkan ke soal berikutnya.
8. Setelah pertandingan selesai, lihat skor akhir atau pilih **Main Lagi**.

### Aturan skor

- Jawaban benar mendapatkan **100 poin**.
- Jawaban salah atau tidak dijawab mendapatkan **0 poin**.
- Skor diperbarui ketika jawaban ronde dinilai.
- Guru dapat menjeda dan melanjutkan pertandingan; timer mengikuti status permainan.
- Poin pertandingan merupakan skor duel, sedangkan XP dan bintang menunjukkan perkembangan profil belajar.

### Dua cara menjawab

**Guru memilih jawaban tim:** peserta berdiskusi atau menyampaikan jawaban, lalu guru memasukkan pilihan masing-masing sisi melalui halaman kontrol.

**Pemain menjawab di tab sendiri:** buka halaman bergabung pada dua tab dalam profil browser yang sama. Isi nama panggilan dan pilih sisi Hijau atau Oranye. Guru memulai pertandingan, sementara setiap sisi menjawab melalui halaman pemain. Untuk demo cepat, gunakan tautan tab pemain di kontrol guru setelah mengisi pemain demo.

> Sinkronisasi prototipe hanya berjalan antartab dalam profil browser yang sama dan pada origin yang sama persis, termasuk protokol, hostname, dan port. Mode ini belum mendukung pertandingan antara laptop dan ponsel terpisah. QR berisi tautan halaman; QR tidak menyediakan koneksi multiplayer antarperangkat.

## Tabungan dan sistem hadiah

**Tabunganku** menyediakan tujuan tabungan, target nominal, tombol pencatatan +Rp2.000, riwayat, toples animasi, dan 50 kotak progres. Pencatatan dibatasi hingga target. Pemain mendapat umpan balik saat mencapai 25%, 50%, 75%, dan 100% dari target.

Sistem hadiah meliputi:

- **XP:** penyelesaian pertama setiap materi, kuis, dan mini-game memberikan 50 XP.
- **Bintang:** penyelesaian aktivitas tersebut juga memberikan 3 bintang.
- **Level:** meningkat setiap 500 XP.
- **Lencana:** terbuka melalui pencapaian tertentu, seperti menyelesaikan materi atau tantangan.
- **Perayaan:** perubahan XP, kenaikan level, lencana baru, dan target tabungan ditampilkan melalui notifikasi serta animasi.

Progres dan penanda hadiah disimpan secara lokal sehingga refresh tidak memberikan hadiah yang sama lagi. Data awal berisi profil contoh, satu materi selesai, dan beberapa lencana untuk keperluan presentasi. Fitur reset di profil mengembalikan data contoh tersebut.

## Fitur pendamping

- **Profil dan pencapaian:** ubah nama panggilan serta avatar, lihat progres, dan koleksi lencana.
- **Papan juara:** tampilkan profil kelas contoh dan hasil duel lokal.
- **Workbook:** akses enam materi melalui QR dan tautan langsung.
- **Ruang guru:** lihat ringkasan demo, kelas, laporan progres lokal, dan bank soal.
- **Admin:** lihat ikhtisar konten dan filter bank soal.
- **Animasi interaktif:** reaksi Koini, umpan balik jawaban, perubahan skor, countdown, dan perayaan kemenangan.
- **Aksesibilitas:** navigasi keyboard, pengelolaan fokus dialog, serta dukungan preferensi reduced motion untuk mengurangi animasi.

## Menjalankan proyek

Pasang Node.js yang kompatibel dengan Next.js 16.4 dan npm, lalu jalankan dari direktori proyek:

```bash
npm install
npm run dev
```

Buka alamat yang ditampilkan terminal. Untuk menjalankan pengembangan pada port 3002:

```bash
npm run dev -- --port 3002
```

Untuk build produksi:

```bash
npm run build
npm run start -- --port 3002
```

Akses aplikasi melalui `http://127.0.0.1:3002`. Gunakan alamat yang sama persis pada semua tab saat mencoba duel. Hentikan server pengembangan sebelum menjalankan server produksi pada port yang sama.

## Teknologi dan struktur utama

Aplikasi dibangun menggunakan Next.js 16.4 App Router, React 19.3, TypeScript, Tailwind CSS 4, Motion, Lucide, Radix Dialog, serta ilustrasi SVG lokal.

| Lokasi | Tanggung jawab |
| --- | --- |
| `src/data/content.ts` | Materi dan bank soal. |
| `src/lib/store.ts` | Profil, reward, tabungan, room, dan logika pertandingan. |
| `src/lib/motion.ts` | Preset serta durasi animasi bersama. |
| `src/components/learning.tsx` | Materi, kuis, mini-game, dan hasil belajar. |
| `src/components/classroom.tsx` | Kontrol guru, pemain, lobby, arena, dan hasil duel. |
| `src/components/game-motion.tsx` | Komponen animasi reusable. |
| `src/components/art.tsx` | Maskot Koini dan ilustrasi SVG. |
| `src/app/[...path]/page.tsx` | Pemetaan halaman aplikasi. |
| `scripts/` | Pengujian fungsional, animasi, dan aksesibilitas. |
| `ui-evidence/` | Konfigurasi dan hasil review visual. |

Data disimpan dengan `localStorage`. Sinkronisasi antartab menggunakan BroadcastChannel dengan fallback storage event. Web Locks digunakan pada browser yang mendukungnya untuk menserialkan aksi room yang bersamaan. Timer pertandingan menggunakan timestamp bersama.

## Batasan prototipe

- Belum tersedia akun, autentikasi produksi, database, atau multiplayer antarperangkat.
- Data lokal dapat berubah atau hilang ketika penyimpanan browser dibersihkan. Data tersebut belum memiliki otoritas dan validasi server.
- Halaman kelas dan admin masih berupa demo; belum mendukung pengelolaan data lengkap. Laporan belum menyediakan analitik seluruh kelas atau pre-test/post-test.
- Tidak ada transaksi uang, rekening bank, maupun integrasi perbankan.
- Audio masih berupa pratinjau nada yang dapat diaktifkan pengguna; paket efek suara permainan belum tersedia.
- QR workbook belum memvalidasi kepemilikan workbook fisik.
- Pengujian perangkat TV fisik, Safari, dan jaminan performa 60 FPS belum dilakukan.
